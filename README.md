# Friend Bot

This project is a bot for Discord with different features. It is based on the [Discord Bot Project Tutorial](https://www.codedex.io/projects/build-a-discord-bot-with-python) as a final project for the Python course.

## Features

It includes:
- Dice roll
- Minigames
- Magic 8 Ball
- Jokes
- Memes
- Word of the day
- Fortune cookie
- Fun facts
- Recommendations for films, series, books, and songs

## Word of the day

The words and definitions are a personal selection.

## Films, series, books and songs

All the films, series, books and songs included are personal choices.
